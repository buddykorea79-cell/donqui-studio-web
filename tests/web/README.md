# 브라우저 내보내기 수동 검증

`npm run dev:web`을 실행하고 데스크톱 Chrome 또는 Edge에서
`http://localhost:5173/tests/web/export-smoke.html`을 엽니다. 개발 서버가 다른 포트를 출력하면 그 포트를 사용합니다.
**Run browser export test**를 누르면 브라우저가 PNG, WAV와 저장소의 `sample.webm`을 가져와 2초 영상을 내보내고 결과 파일을 다시 디코딩합니다.

자동 확인 항목:

- 결과 영상의 해상도 640×360과 재생 시간
- 60개 영상 패킷과 각 패킷의 30fps 타임스탬프
- 원본 사진의 색상, 자막 흰 글자와 어두운 배경 픽셀
- 두 번째 영상 구간과 자르기 시작점을 반영한 원본 프레임의 픽셀 차이
- 오디오 배치 전·후 무음과 동일 음원의 0.7/1.0 음량 비율

성공하면 화면에 `PASS`와 측정값, 재생 가능한 영상과 다운로드 링크가 나타납니다.
화면의 영상을 직접 재생해 자막과 음원을 추가로 확인합니다.
지원 코덱에 따라 MP4 또는 WebM이 만들어집니다. 브라우저별로 반복 실행하면 각 코덱 경로를 확인할 수 있습니다.
이 검증은 서버 업로드, 실제 화면 공유 권한, 긴 프로젝트의 메모리 사용, 모든 입력 코덱을 검증하지 않습니다.

이 페이지는 개발 서버에서만 사용합니다. `index.html`에서 참조하지 않고 Vite의 public 폴더 밖에 있으므로 `dist-web` 배포물에 포함되지 않습니다.

## Remotion 효과·자막 회귀 검증

같은 개발 서버에서 `http://localhost:5173/tests/web/effects-smoke.html`을 열고 **Run effects export test**를 누릅니다. 약 12초 가로 영상과 0.8초 세로 영상을 실제 인코딩한 후 다시 디코딩합니다.

- 기존 10개 효과와 효과 없음: 효과마다 세 시점에서 미리보기 렌더러와 디코딩한 결과의 평균 RGB 오차를 비교합니다. 각 효과가 효과 없음과 실제로 다르게 보이는지도 검사합니다.
- 사진의 전체 보기(`contain`)와 화면 채우기(`cover`), 0.2초부터 잘라낸 영상과 이동 효과를 확인합니다.
- 한글·여러 줄 SRT 가져오기/내보내기, 자막 시작 포함·끝 제외 시각, 상단 위치·글자 크기·색상·배경과 기존 클립 자막을 확인합니다.
- 별도 음원의 0.4/0.8 음량 비율, 두 0.25 음량 트랙을 겹친 결과와 1.0 기준의 비율, 구간 밖 무음을 측정합니다.
- 360×640 세로 영상에서 틸트·화면 채우기·하단 여러 줄 자막·배경 끄기를 확인합니다.

성공하면 `PASS`, 효과별 오차·음량 측정값, 두 영상과 다운로드 링크가 표시됩니다. 실패하면 `FAIL`에 실패 지점과 그때까지 수집된 결과가 남습니다. 이 페이지는 실제 브라우저 코덱을 사용하므로 단위 테스트의 mock 결과와 별개입니다. UI 조작·저장 복원·화면 녹화 권한·장시간 내보내기는 별도로 확인해야 합니다.
