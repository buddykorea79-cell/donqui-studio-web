## 기존 전체 테스트 결과

전체 `npm run test`를 한 차례 실행해 **3,458 통과, 2 실패, 9 건너뜀**을 확인했습니다. 이 실행 후 추가한 웹 회귀 테스트는 위의 `test:web` 결과에 포함됩니다.

- `electron/media/clipEffects.test.ts`: 샌드박스가 localhost 연결을 차단해 실패했습니다. 같은 파일을 로컬 연결이 가능한 환경에서 다시 실행한 결과 18개 통과, 2개 건너뜀입니다.
- `electron/native-bridge/services/compositorViewService.test.ts`: addon이 없다는 기대와 달리 이 기기의 네이티브 addon을 발견하여 실패했습니다. 웹 경로에서 사용하지 않는 기존 데스크톱 테스트이며 관련 코드는 수정하지 않았습니다.

처음 Vitest가 Windows 샌드박스의 임시 캐시 rename 권한 오류로 테스트를 로딩하지 못해, `TEMP`와 `TMP`를 작업 폴더의 `.local/web-test-temp`로 지정한 뒤 실행했습니다. 테스트 로직을 건너뛰거나 결과를 성공으로 치환하지 않았습니다.
